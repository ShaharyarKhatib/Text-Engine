# 🔐 Text Engine

> A lightweight browser-based text transformation tool for encoding and decoding text using a custom transformation algorithm.

---

## ✨ Overview

**Text Engine** is a simple and modern web application that allows users to transform text using a custom encoding and decoding algorithm.

The application works completely in the browser, so no backend or database is required.

Users can:

- ✨ Encode text
- 🔓 Decode encoded text
- 📋 Copy transformed text
- 🧹 Clear input and output
- 🔢 View character counts
- ⚡ Process text instantly
- 🔒 Keep text processing local in the browser
